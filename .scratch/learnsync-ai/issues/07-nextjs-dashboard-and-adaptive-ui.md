# 07: Next.js Frontend Dashboard, Virtual Folder UI & Adaptive Study Interface

**What to build:**
Create the modern, responsive React / Next.js web client with Tailwind CSS following the minimalist Perplexity design aesthetic. The UI includes the onboarding learning-style selector, nested virtual folder browser, real-time workload score & mode indicator banner, multimodal study artifact viewer (rendering Markdown, SVG/Mermaid diagrams, and interactive code blocks), flashcard review UI, and Burnout Guard micro-task modal.
